การเล่น

ค้นหาเพลงในแอป (ไม่บังคับ)

ใส่ YouTube API key (ฟรี) เพื่อค้นหาเพลงได้ในแอปเลย ถ้าไม่ใส่ ปุ่มค้นหาจะเปิดหน้า YouTube ให้แทน

วิธีขอ API key ฟรี
  1. เข้า console.cloud.google.com แล้วล็อกอินด้วยบัญชี Google
  2. สร้างโปรเจกต์ใหม่ ตั้งชื่ออะไรก็ได้
  3. ไปที่ APIs & Services → Library ค้นหา YouTube Data API v3 แล้วกด Enable
  4. ไปที่ Credentials → Create credentials → API key คัดลอกมาวางด้านบน
  5. แนะนำ: ในหน้า key ตั้ง Website restrictions เป็น เพื่อไม่ให้คนอื่นเอาไปใช้

โควตาฟรีค้นหาได้ประมาณ 100 ครั้งต่อวัน

ติดตั้งลงโทรศัพท์

Android (Chrome): แตะเมนู ⋮ มุมขวาบน → ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก

iPhone (Safari): แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → เพิ่มไปยังหน้าจอโฮม

สำรองข้อมูล

รายการเพลงและเพลย์ลิสต์เก็บอยู่ในเครื่องนี้เท่านั้น ส่งออกเป็นไฟล์ไว้เผื่อเปลี่ยนเครื่อง

เรื่องโฆษณาและการเล่นตอนปิดจอ

  • แอปนี้ไม่มีโฆษณาของตัวเอง และเล่นผ่านตัวเล่นทางการของ YouTube (โหมดความเป็นส่วนตัว) แต่ บางคลิป YouTube อาจยังแทรกโฆษณาในตัวเล่น ซึ่งแอปปิดให้ไม่ได้
  • การเล่นตอนล็อกจอขึ้นกับรุ่นเครื่องและเบราว์เซอร์ ถ้าเพลงหยุด ให้ใช้ โหมดจอดำ แทน: จอติดอยู่แต่ดำสนิท กินแบตน้อย ใส่กระเป๋าได้
  • คลิปที่เจ้าของปิดการเล่นนอก YouTube จะเล่นในแอปไม่ได้ แอปจะข้ามไปเพลงถัดไปให้
